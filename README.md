# South-City-International-School

Project Overview
The Tripwire Security System is an Arduino Uno-based security project designed to detect unauthorized movement across a protected area. It provides a simple, effective, and affordable solution for basic security needs. The system works by monitoring a tripwire mechanism, and whenever the wire is disturbed or interrupted, the Arduino Uno detects the change and immediately activates an alarm using a buzzer and LED. This allows users to receive an instant warning whenever an intrusion occurs. The project demonstrates the practical application of embedded systems, sensors, and microcontroller programming in developing a reliable security device.

Mission Objective
The main objective of this project is to create a low-cost, efficient, and reliable intrusion detection system using easily available electronic components. It aims to introduce students to Arduino programming, sensor interfacing, digital input/output operations, and real-time event detection. The project also encourages innovation by providing a platform that can be expanded with additional modules and advanced technologies.

Key Features
The system offers real-time intrusion detection with immediate audio and visual alerts. It is programmed in C++ using the Arduino IDE, making it easy to understand and modify. The design is compact, affordable, and beginner-friendly while remaining reliable for homes, offices, laboratories, and restricted areas. The project can be enhanced by integrating GSM or Wi-Fi modules for remote notifications, LCD displays for status monitoring, motion sensors for improved detection, SD card modules for data logging, and camera modules for surveillance, making it scalable for future applications.

Setup Instructions
Connect the tripwire sensor to the Arduino Uno digital input pin and attach the buzzer and LED to the designated output pins with appropriate resistors. Power the Arduino Uno using a USB cable or external power source. Open the Arduino IDE, upload the C++ program, and verify successful compilation. Position the tripwire across the area that requires protection and test the system by interrupting the wire. When the tripwire is triggered, the Arduino instantly processes the input signal and activates the buzzer and LED, alerting users to unauthorized movement. This simple setup demonstrates how basic electronic components and embedded programming can be combined to create an effective, low-cost, and easily expandable security solution suitable for both educational purposes and practical application

Materials used :Arduino UNO , Jumper wires , Buzzer , LDR , LED Cable
